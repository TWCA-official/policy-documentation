## Contact

For questions regarding these documents, or to submit a Certificate Problem Report (such as suspected Key Compromise or certificate mis-issuance), please contact ca@twca.com.tw, as described in Section 1.5.2 and Section 4.9.3 of the applicable CP/CPS.

This repository does not accept issues or pull requests as a channel for Certificate Problem Reports.
